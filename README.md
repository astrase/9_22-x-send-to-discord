bot使用手順

## 1.拡張機能を入れる

まずZIPを展開します。

##Chromeの場合

chrome://extensions をブラウザで開きます。
「デベロッパーモード」をオンにします。
「パッケージ化されていない拡張機能を読み込む」で、展開した中の chromeフォルダーを選びます。


##Firefoxの場合
about:debugging#/runtime/this-firefox をブラウザで開きます。
「一時的なアドオンを読み込む」を押します。
firefoxフォルダー内のmanifest.jsonを選びます。


Firefoxの一時読み込みは、ブラウザ終了で解除されます。

# 2.Discord Webhookを設定する

Discordの送信先チャンネルの設定 →「連携サービス」→「ウェブフック」でWebhookを作成し、URLをコピーします。
ブラウザの拡張機能アイコンを押して設定画面を開きます。
URLを貼り、自動送信にチェックを入れて「保存」を押します。
「Discord接続テスト」でメッセージが届くことを確認します。
Xのタブを再読み込みして、未いいねの投稿にいいねします。


同じ投稿は、初期設定で24時間以内の再送を防止します。設定画面で期間を変更できます。
